- id: f01
  title: 三类交易点总纲（逆势点／转势点／顺势点）
  type: framework
  source_chapter: |
    第四章 第四节 开篇（月线调整逆势点、转势点、预期上涨顺势点）；
    全章骨架，第一节至第六节每节标题均按此三分命名（图 4-3～4-35）
  source_quote: |
    "我们想要找到符合波动规律的周期、结构的精准交易点，唯有通过浪形内部结构分析，找到正运行的调整浪逆势点、转势点和上涨浪顺势点。"
  summary: |
    本章总纲：任何一笔交易点都必须先归入三类之一，三类各有不同的成立条件与止损锚。
    ①逆势点——正在运行的调整浪（或反弹浪）走到极端、次一级结构刚结束而高一级尚未确认时逆势进场，赚"调整结束"这一段。
    ②转势点——价格上破关键前高（下跌中）或下破关键前低（上涨中），确认调整已在某点结束、趋势方向改变。
    ③顺势点——转势之后，预期上涨/下跌浪内部的次一级回调出现结束信号并验证收在前低/前高之上，顺势加仓的位置。
    同一个价格点可以同时是某一级别的逆势点和另一级别的转势点，级别由其所处浪级决定。
    三类的止损都锚定在被抓结构的极值之外，目标都指向高一级结构"具备结构条件/出现结束信号"。
    判定不靠形态名称，而靠内部结构：先看该点是否"具备结构条件"，再看是否"出现结束信号"。

  summary: |
    第二至第五节开篇都重复同一套三选一的入场决策，构成全书入场路线图。
    路径 A：等大周期调整内部结构的"三浪二次分解"极端区，逆势抓底/抓顶——位置最好，目标可上调一级。
    路径 B：极端区错过，就等大周期调整出现"转势信号"（上破关键高点），再逆势抓次一级回调之底，顺预期趋势交易。
    路径 C：大周期已确立上涨趋势，则在趋势中逆势抓次一级短期调整之底，顺趋势交易，即作者所说"真正的顺势而为"。
    取舍依据是"所处位置"：位置越极端，目标越大、止损越近、风险回报比越好；位置一般则只做次一级。
    抓不到 A 就不硬做，宁可等 B；B 也没有就等 C，不提前动手（否则"抓在半空中"）。
    书中另提醒：一个周线级别调整的上破空间虽大，但转势点本身往往不是好交易点，故路径 B 的重点是等回调而不是追突破。

  type: procedure
  source_chapter: |
    第四章 第五节 一（月线三浪调整"剪刀"式一次分解）；
    同构表述见第二节开篇、第三节开篇、第四节开篇、图 4-6 判读
  source_quote: |
    "要逆势精准抓年线调整之底，首先需根据月线三浪结构特性、支撑点，根据月线（C）内部结构周线三浪结构特性等待合适的周线 C 浪时机，根据 C 内部结构日线三浪结构特性等待合适的日线 {c} 浪时机"
  summary: |
    自上而下逐级下钻的等待链：大级别先定"哪一浪在跌"，小级别再定"这一浪内部跌到第几段"。
    四级同时成立时，一个 60 分线低点就是日线、周线、月线、年线四级的共同底，作者称为"抓 60 分线（c）之底的同时抓日线、周线、月线、年线之底"。
    抓顶同理，只是把"底"换成"顶"、把"下跌段"换成"反弹段"。
    该链条要求每一步都等前一步给出条件，不能跳级；跳级就是书中批评的"提前动手"。
  inputs: 月/周/日/60 分四级 K 线图、当前浪级标号、各级关键高低点
  outputs: 一个跨四级共振的低点（或高点）＋该点所属级别＋对应止损位
  steps:
    - 月线层面确认（C）浪是否具备结构条件
    - 周线层面确认 C 浪内部已走到合适的下跌段
    - 日线层面确认 {c} 浪内部结构
    - 60 分线层面定位（c）之底并设止损
    - 逐级验证并上调目标
  missing_conditions: 书中未给各级"合适时机"的量化阈值，仍需人工判读结构条件

  summary: |
    同一走势点因所处大周期位置不同，交易目标必须不同——这是本书的目标定位决策框架。

    目标上调时止损不变（仍锚定在该低点以下），于是风险回报比随位置上移而改善。

- id: f05
  title: 交易点三件套（触发信号＋止损锚＋目标锚）
  type: framework
  source_chapter: |
    第四章 第二节 一（图 4-5 前正文）；全章每个交易点的标准写法，例见第二节二、第三节二、第五节一
  source_quote: |
    "可把目标直接上调为日线上涨具备结构条件之时，设止损于“（c3）下移”低点以下。"
  summary: |
    书中每个交易点都按同一模板书写，可抽成"三件套"。
    ①触发信号——某个具体价格行为（上破某高点、下破某低点、某调整验证收在某低点以上）。
    ②止损锚——"设止损于 X 低点以下/高点以上"，X 永远是被抓结构的极值，不用百分比、均线或固定点数。
    ③目标锚——"目标定为高一级结构具备结构条件之时"或"出现结束信号之时"，并按位置可上调。
    三者缺一即不构成可执行交易点；书中凡只写信号处，多会补一句"设止损于……"。
    止损被击穿同时也是判断失败的验证条件，故风控与结构判读共用同一套坐标。

- id: f07
  title: 转势双条件确认（上破关键高点＋调整验证收回）
  type: procedure
  source_chapter: |
    第四章 第三节 三（图 4-16 后正文）；
    同句式见第三节一、第三节二、第四节一（图 4-18 后多条）、第五节二、第六节
  source_quote: |
    "{a0} 上破“（b）下移”高点是周线调整转势点，{b0} 调整内 60 分线三浪逆势点、出现结束信号验证收在 {a0} 低点以上的点，是预期周线上涨顺势点，设止损于 {a0} 低点以下。"
  summary: |
    转势不是一个价格行为，而是两个条件同时成立。
    ①上破——价格上破被调整浪的关键反弹高点（下跌中）／下破关键回调低点（上涨中）。
    ②验证——其后的反向调整"出现结束信号并验证收在该上破段的低点以上"。
    书中标准句式："A 上破 B 高点，和 C 调整出现结束信号验证收在 A 低点以上，是……转势点，也是……顺势点"。
    只有①没有②时，书中只称"转势信号"，并提示"后市并没有直接运行上涨"（图 4-6 的 30 分线即此情形）。
    该框架也解释了为何转势点常与顺势点重合：验证完成的那一刻，两者是同一个点。
  inputs: 上破段低点、被上破前高、其后回调的结构标号
  outputs: 转势点（确认）＋顺势点（加仓点）＋止损位
  steps:
    - 记录被上破的关键高点及其所属浪级
    - 等待其后调整走完次一级三浪
    - 检查该调整是否出现结束信号
    - 检查是否验证收在上破段低点以上
    - 两项同时成立才记为转势点/顺势点
  missing_conditions: 未上破时的处理分支书中只作提示，未给完整流程

- id: f08
  title: 调整形态三分（剪刀／镰刀／双节棍）→抓底节奏
  type: framework
  source_chapter: |
    第四章 第三节 二（图 4-14 前正文）；
    第一节二（剪刀式）、第二节二（镰刀式）、第三节三（双节棍式）、第四节三、第五节
  source_quote: |
    "日线 {a}、{b}、{c} 三浪调整“镰刀”式（见图 4-14），{c} 内部结构 60 分线（a）、（b）、（c）三浪“剪刀”式，根据“剪刀”式结构特性在其一次分解和二次分解具备结构条件之时分批买入，或在（a）上破“（b）再下移”高点之时买入，都是逆势抓周线之底的时机。"
  summary: |
    调整浪先分三种结构形态，形态决定抓底的节奏与触发条件。
    剪刀式——高点逐级下移、低点逐级下移，内部可一次/二次分解；对策是在一次、二次分解具备结构条件处"分批买入"，或（c）上破（a）高点时买。
    镰刀式——C 浪内部为次一级三浪；对策是等 C 内次一级三浪走完（c1 具备结构条件＋a2 上破 b1 高点）。
    双节棍式——内部为复杂折返；对策是盯次一级三浪的极端与结束信号，或（c）上破（a）高点。
    形态判断错，抓底节奏就错：书中反复用"根据'剪刀'式结构特性……""根据'双节棍'式结构特性……"引出对策。
    三种形态之间会互相演化（见 f09、f16），故形态是"当前工作假设"而非终局结论。

- id: f09
  title: 一次／二次／三次分解的演化判定与升级
  type: procedure
  source_chapter: |
    第四章 第五节 二（图 4-28 前正文）；
    另见第三节一（图 4-11 后）、第四节二（图 4-21）、第五节二（图 4-30 三次分解）
  source_quote: |
    "A3 下破“（C）下移”低点是月线三浪调整从“剪刀”式一次分解演变成二次分解信号（见图 4-28），需重点关注 A3、B3、C3 三浪调整结构。"
  summary: |
    "一次分解/二次分解/三次分解"是本书描述调整浪延伸层级的坐标，也是判断"调整是否还要继续"的开关。
    升级条件写得很明确：某个低点被下破，就把该级别从一次分解升级为二次分解（如 A3 下破"（C）下移"低点）。
    书中用"下移／再下移／三下移／四下移"的标号记录同级浪的逐级延伸，标号本身即分解层级。
    操作含义：一次分解位可轻仓试，二次分解位加仓，三次分解位才谈"极端"。
    若在升级条件出现前就重仓，等于把"一次分解"当成了终点。
  inputs: 当前浪级标号（含"下移/再下移"）、各关键低点水平位
  outputs: 当前分解层级＋下一步升级触发位＋对应仓位级别
  steps:
    - 标出当前调整浪的高点序列与低点序列
    - 检查低点是否已被下破（升级条件）
    - 下破则把该浪改标为下一级分解
    - 按新层级重设目标与仓位
  missing_conditions: 三次以上分解（四次分解）书中只举中银证券一例，未给通用判据

- id: f10
  title: 顺势点识别流程（趋势确立→等回调→等结束信号→验证收回）
  type: procedure
  source_chapter: |
    第四章 第六节 开篇（"何为顺势？"）；
    环境前提见第六节一（"成功率高的日线顺势点……"）；
    "转势点并非好交易点"见第四节二（图 4-21 后正文）
  source_quote: |
    "何为顺势？C 上破 A 高点确立高一个级别的上涨趋势，预期“B 上移”内次一级三浪回调出现结束信号，验证收在 B 浪低点以上的点，才是高两级上涨的顺势点。"
  summary: |
    顺势点有严格定义，不是"趋势向上就买"。
    ①趋势确立——C 上破 A 高点，高一级上涨确立。
    ②等回调——预期"B 上移"内部走次一级三浪回调。
    ③等结束信号——该回调出现结束信号。
    ④验证——收在 B 浪低点以上。
    四条同时满足的那个点，才是"高两级上涨的顺势点"。
    60 分线与日线的对应版本：60 分线（c）上破（a）高点确立日线上涨，等"（b）上移"内 5 分线三浪回调结束并验证收在（b）低点以上。
    环境前提：该流程要在周线上涨或预期上涨趋势中做；周线下跌趋势中做日线顺势点成功率很低。
  inputs: 上一级趋势确立信号（上破关键高点）、次一级回调结构、回调结束信号
  outputs: 顺势点（加仓点）＋止损位（该回调结构低点以下）
  steps:
    - 确认高一级趋势已由上破关键高点确立
    - 等次一级回调走完三浪
    - 等回调出现结束信号
    - 验证收在上一级低点以上
    - 定止损于该回调低点以下
