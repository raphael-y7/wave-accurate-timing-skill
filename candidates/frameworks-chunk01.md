- id: f01
  title: 周期—结构—形态三要素分段定位法
  type: framework
  source_chapter: 前言（"波浪理论内部结构分析原理"段之后，《精准择时》定位段）
  source_quote: |
    《精准择时》是在《精准数浪》展示各种结构基础上，根据周期、结构、形态对走势进行分段，找到每浪起点、终点，着重找到每个周期、每个结构的调整逆势点、转势点，上涨浪顺势点等关键买点，再结合政策、基本面、成交量等选板块、个股。
  summary: |
    - 定位一段行情的三个坐标：周期（本级与次一级的对应）、结构（浪形是否完整、是否具备条件）、形态（剪刀/镰刀/双节棍/三角形/上倾/下倾）。
    - 用三坐标把走势"分段"，先标出每一浪的起点与终点，而不是直接猜买卖点。
    - 分段完成后，逐段标注三类可交易点：调整浪逆势点、转势点、上涨浪顺势点。
    - 这些点构成"关键买点"候选池，之后才叠加政策、基本面、成交量做选股/选板块。
    - 顺序不可颠倒：先分段定位，后选股；不先定级就选股，结论不可复用。
    - 输出：一张带级别的分段图＋每段的关键点清单。

- id: f02
  title: 多周期共振关键买点筛选
  type: framework
  source_chapter: 前言 第 1 段
  source_quote: |
    更稳妥的是通过两个或多个周期、结构配合，找到关键买点，此点不但是本周期调整浪逆势点（或上涨浪顺势点），也是更大的一个甚至两个、三个周期的逆势点（或上涨浪顺势点）。
  summary: |
    - 单个周期上的逆势点／顺势点只算"普通买点"，可靠性有限，容易变成抢反弹。
    - 升级条件：同一个价格点同时是本周期、以及更大一级（甚至两三级）周期的逆势点或顺势点。
    - 操作路径：先在次一级确认调整结束，再回溯检查该低点是否落在上级的调整结束区／关键支撑上。
    - 共振的周期数越多，止损越明确（落在最下级浪起点之外），仓位可越重。
    - 输出：按"共振周期数"排序的买点清单，而不是单一买点。
    - 对应作者反复强调的"一点三级顺势（共振）"场景，是全书胜率最高的落点。

- id: f03
  title: 交易前三问（位置／机会／风险回报比）
  type: framework
  source_chapter: 前言 末段「学习波浪理论内部结构分析目的」
  source_quote: |
    学习波浪理论内部结构分析目的：
    知道所处位置及是否适合交易；
    知道等什么样的机会；
    提前核算风险回报比。
    实际交易有此足矣！
  summary: |
    - 第一问：现在处于什么位置，这个位置是否适合交易（不是所有位置都能做）。
    - 第二问：如果要做，应该等什么样的机会出现——要具体到某个结构、某个信号，不能是"等回调"。
    - 第三问：这笔交易的风险回报比是多少，能否在进场前算清（止损位与目标位都要有结构依据）。
    - 三问都有答案才动手；任一问答不上来，说明级别没定清，退回定级步骤。
    - 这是一个"准入闸门"，不是分析步骤：分析做完后用它过滤掉不合格的机会。
    - 输出：做／不做＋等待清单。
  tags: [decision, checklist-gate, risk-reward, position]

  title: 浪级递归定级法（八浪循环上下递归）
  type: framework
  source_chapter: 特色术语 开头（图 5「经典八浪循环」之后正文）
  source_quote: |
    往上，1、2、3、4、5 上涨构成大一级的月线第（1）浪，A、B、C 三浪构成大一级第（2）浪调整（见图 1-3），月线（1）、（2）、（3）、（4）、（5）构成年线第 {1} 浪。
  summary: |
    - 规则一（向上递归）：本级五浪上涨整体＝大一级的第 1 浪（推动）；本级 A、B、C 三浪整体＝大一级的第 2 浪（调整）。
    - 规则二（向下递归）：本级每一个推动浪（1、3、5）由次一级五浪组成；每一个调整浪（2、4 与 A、B、C）由次一级三浪组成。
    - 同一段 K 线因此可同时被读成"本级三浪"和"上级一浪"，必须先声明基准级别。
    - 级别标号体系固定：年线 {1}～{5}／{A}{B}{C}、月线（1）～（5）／（A）（B）（C）、周线 1～5／A B C、日线 {i}～{v}／{a}{b}{c}、30 分（i）～（v）／（a）（b）（c）、5 分 i～v／a b c。
    - 应用：任何数浪结论都必须写明"这是 X 线级别的第几浪"，否则结论无效、无法与止损目标挂钩。
    - 输出：带级别的浪形标注（含"本级／上级／次一级"三行对照）。

- id: f06
  title: 三种复杂调整结构的识别（剪刀式／镰刀式／双节棍式）
  type: framework
  source_chapter: 特色术语 第 1～3 条（图 9、图 10、图 11）
  source_quote: |
    “剪刀”式、“镰刀”式、“双节棍”式调整是 {a}、{b}、{c} 三浪中 {b} 浪分解的结果，与普通的三浪同级别。大到月线、年线，小到 5 分线、1 分线，都会出现这些结构模式，且有多种不同的形态。
  summary: |
    - 共同前提：复杂调整都是 {a}{b}{c} 三浪中 {b} 浪单独分解或多次分解的结果，级别与普通三浪相同。
    - 剪刀式：{b} 浪一次分解为 {a}{b}{c} 反弹下倾；二次分解则在 {b} 内再分 {a0}{b0}{c0}，{b}、{c}、C 逐级下移（"下移""再下移"是运行中的动词式称呼）。
    - 镰刀式：{b} 浪二次分解，反弹高点一级比一级低、低点不断下移，空头明显占优，形似镰刀。
    - 双节棍式：{b} 浪一次分解成三浪下倾后，这三浪又同时再分解，多空争夺难解难分，最终以空头占优结束。
    - 判别顺序：先确认是否普通三浪 → 再看 {b} 是否分解 → 再看分解是一次、二次还是三浪同时再分解。
    - 铁律：分解不改变原三浪级别，不能把内部结构升格成高一级的浪（否则定级全错）。
    - 输出：结构名称＋分解层级＋级别不变声明。
  tags: [framework, pattern-recognition, complex-correction, core-method]
  task_ids: [task-15, task-17, task-04, task-02]

  type: framework
  source_chapter: 特色术语 第 8 条（图 17）
  source_quote: |
    浪中浪结构：一个调整（或复杂调整）结构中包含另一个调整（或复杂调整）结构，有时还包含复杂的反弹结构，不改变这个调整结构的级别。看似复杂，其实两结构之间的连接清晰可见。

    - 用途：一套结构知识双向使用，减少记忆量并保持判定口径一致。
