## 一、浪级符号体系

| 周期 | 五浪 | 三浪 |
|---|---|---|
| 年线 | {1} {2} {3} {4} {5} | {A} {B} {C} |
| 月线 | （1）（2）（3）（4）（5） | （A）（B）（C） |

| 日线 | {i} {ii} {iii} {iv} {v} | {a} {b} {c} |

## 二、结构与判定术语

**基础浪**：正在运行的最高级别推动浪。其内次一级为细分浪，再往下为"细分浪中细分浪"。可自选把某一级当基础浪，但要明白它实际是大浪级的细分浪。

**细分浪**：基础浪内部次一级的浪。同一段 K 线在不同锚定下身份不同。

**具备结构条件**：该级别浪形在结构上已走完最小构成（如 {a}{b}{c} 三浪），但仍在运行、仍可继续演变；**不是结束**。只能用于主动出局/减仓/设目标，不能据此反向开仓。

**结束信号**：次一级三浪反转并"验证收在"关键低点/高点之外（如 {a} 上破 {b} 高点、调整验证收在 {a} 低点以上）。此时该浪终止、方向改变，其低（高）点就是反向浪起点。

**逆势点**：调整浪（或反弹浪）内部结构一次/二次分解到极端、具备结构条件之处的点；在此逆势抓底（或抓顶），顺更大周期之势。

**转势点**：调整（反弹）结束信号出现、并验证收在关键低点（高点）之外的点；原趋势反转的确认点。

**顺势点**：高一级趋势已由"次一级三浪上破本级别前高"之类信号确立后，本级别调整出现结束信号、且验证收在关键低点（高点）之上的点。

**关键买点**：同时满足"本级别调整结束信号/具备结构条件"＋"所处位置使目标可上调"＋"止损空间可接受"的点。

**多空分界点**：某级别"双节棍"等结构具备结束条件时的那个低点（高点）；在其上方看多、下方看空，破与不破决定该级别多空归属，它本身常是反向同级浪的起点。

**上移 / 下移**：同一浪级标号因结构演变而整体抬高/降低的重新标注（"B1 上移""{c} 再下移"）；是结构运行中的动词，级别不变。

## 三、形态术语

**剪刀式**：普通三浪调整中 {b} 浪一次或二次分解为 {a}{b}{c} 反弹下倾结构，{b}、{c} 与 C 逐级下移，形似剪刀张口向下。

**镰刀式**：{b} 浪一次分解为 {a}{b}{c} 下倾后，{b} 浪再分解为 {a0}{b0}{c0}；反弹高点一级比一级低、低点不断下移，末端急跌，形似镰刀；空头明显占优。

**双节棍式**：{b} 浪一次分解成 {a}{b}{c} 下倾后，这三浪**同时**再分解；多空争夺难解难分，最终空头占优；最易产生多空分界点，也最易演变成不规则结构。

**调整上倾**：出现在各级三浪反弹的 B 浪调整位置，本应下跌的调整实际向上倾斜（{b2} 上破 {a2} 高点），预示 C 浪强劲上涨。

**反弹下倾**：出现在各级三浪调整的 B 浪反弹位置，本应上涨的反弹实际向下倾斜（{b2} 下破 {a2} 低点），预示 C 浪重挫。

**三角形**：一般出现在各级 B 浪调整中，收敛形态；确立之时预示 C 浪强劲上涨。出现在 {a2} 位是"大一级 B 浪未来可能演变成三角形或上倾"的信号。

**不规则结构**：市场没有按常规结构走、但后市已出现确定本浪结束信号，则该段为不规则结构（不规则底/顶）。

**浪中浪**：一个调整结构中包含另一个调整结构，有时还包含复杂反弹结构，**不改变这个调整结构的级别**。

**组合结构**：{a}{b}{c} 三浪**同时**分解（而非只有 {b} 分解）。在五浪推动上涨后属"蓄势"，不改变级别。

## 四、交易与风控术语

**一点三级顺势（共振）**：同一个点同时是本级别、高一级、高两级（如周线、月线、年线）的顺势点；风险回报比最好的买点之一。

**位置**：不是价格高低，而是"本级别浪处在大一级浪的哪一段（A/B/C 或 1/2/3/4/5）、大一级又处在更大一级的哪一段"。

**一次分解 / 二次分解**：{b} 浪被分解一次为一次分解；其中 {b} 再被分解为二次分解。分解次数决定"极端程度"。

**主动出局 / 被动出局**：主动＝上涨（下跌）具备结构条件时按计划离场；被动＝出现反转（结束）信号后被迫离场。

**可接受止损空间**：当前点到关键支撑/止损点的距离是否小到值得下单；定性判断，决定"这个点做不做、做多重"。

**隐藏的转势信号**：日线上看不出来、但在 30 分线/60 分线上已出现"次一级三浪上破前高"的转势信号。

**技术止损点**：浪形起点之外的那条线，破了就认错。
