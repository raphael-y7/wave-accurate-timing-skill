## R — 原文

> 「在出现浪形结束信号之时反向交易必须设止损于本浪起点以下，因为即使本浪出现结束信号也存在继续演变的可能性；一旦出现演变，其时间和幅度难以预计，且还有浪中浪结构，波动幅度难以提前预测，有时日线一浪波动幅度比周线一浪波动幅度还大。」（第一章 第四节）

> 「即此点买入目标可定为周线、月线、年线上涨，止损点统一设置在 B3 低点以下，也可分开设置。目标定为周线上涨，止损点是 B3 低点以下，主动出局点为 C3 具备结构条件之时的点，被动出局点是 C3 上涨出现反转信号之时。」（第八章 第十六节）

> 「{a2}、{b2}、{c2} 三浪调整二次分解距离 A 浪低点达到可接受止损空间，则逆势抓“{c2}再下移”之底成为好的逆势抓周线 B 浪之底时机（距离 A 浪低点越近仓位可适当越重些），并可设止损于 B 或 A 浪低点以下。」（第一章 第二节 三）

## I — 自述

这是把「分析」变成「可下单声明」的一步。作者要求任何一笔交易在进场前就必须写清四件事，缺一件就不算完整计划：

1. **止损位**：永远放在本浪起点之外——做多放在调整浪低点以下，做空放在反弹浪高点以上。理由：结束信号之后仍可能演变，且「浪中浪」使波动幅度难以预估（「有时日线一浪波动幅度比周线一浪还大」）。止损不接受高一级的止损（比如做日线却用周线低点），否则风险不可控。
2. **可接受止损空间**：当前价到止损位的距离是否小到「值得下单」。这是定性判断，作者不给定值——它直接决定「这个点做不做、做多重」。空间越小，仓位可越重。
3. **目标位**：设在高一级浪「具备结构条件」处，而不是等反转信号。这意味着目标常常是「下一个结构走完的地方」，不是固定百分比。
4. **出局方式**：主动出局（到达结构条件，按计划走）与被动出局（出现反转信号，被迫走）必须事先分开设。作者认为前者决定收益、后者决定回吐。

此外还有「止损逐级迁移」：随着行情推进，止损只上移不下移（做多），把浮盈锁住。

## E — 执行步骤

**输入契约（缺项先问）**：
- 入场点与入场理由（U04/U07 输出）；
- 本浪起点价位（结构最低点/最高点）；
- 高一级目标结构位置；
- 用户的风险偏好（决定可接受止损空间，原书不给默认值）。

**步骤**：

1. **定止损位**：写「本浪起点之外」的具体价位；若用户想用高一级止损，说明风险并拒绝。完成标准：止损价位＋依据。
2. **算可接受止损空间**：给出百分比或点数，并与用户风险偏好比对。完成标准：空间数值＋是否可接受。
3. **定目标位**：写「高一级浪具备结构条件处」的具体价位或区间。完成标准：目标价＋依据。
4. **分设主动/被动出局**：主动＝到目标走；被动＝出现反转信号走。完成标准：两类出局条件各一行。
5. **写止损迁移规则**：涨到哪个结构后止损上移到哪。完成标准：迁移表（触发价→新止损）。

**判停点**：若浪起点无法确定（结构不明），停在步骤 1，输出「止损不可定，不建议下单」。

**输出契约**：

| 字段 | 内容 |
|---|---|
| 入场 | 价位＋理由 |
| 止损 | 价位＋依据（浪起点外） |
| 可接受止损空间 | 百分比/点数＋是否可接受 |
| 目标 | 价位/区间＋依据（高一级结构条件） |
| 主动出局 | 条件 |
| 被动出局 | 条件 |
| 止损迁移 | 触发价→新止损 |

## B — 边界

- **不要用于**：无结构标注时凭感觉设止损；用固定百分比替代浪起点（作者明确反对）；把「不设止损」当长线投资。
- **「本浪」的取法（NR-03 核定）**：本浪＝该笔交易依托之浪——顺势加仓依托新启动的次一级一浪（止损＝其起点低点，第一章黄金 2206 例 a1/a3/a5 低点）；逆势/转势依托期望的反向浪（止损＝其起点即结构极值，第四章 c1 例）；两场景同属本规则，非两套口径，不按「更外侧」一概取之。
- **作者警告的失败模式**：止损设在结构内部（被正常波动打掉）；不设主动出局点导致利润回吐；止损下移（亏损扩大）。
- **作者盲点**：A 股 T+1 使「当日跌破止损」无法执行；涨跌停/跳空使「低点以下止损」可能穿越；作者未讨论滑点与交易成本；「可接受止损空间」无量化标准（见 needs-review NR-07）。
- **失效条件**：极端行情跳空；流动性不足无法按价成交；停牌复牌。
