> 「结构预测未来」「形态预测未来」「周期预测未来」「所处位置对走势的影响和预测」「关键阻力点、支撑点、多空分界点对走势的影响和预测」（第三章 第一节 五条小标题）

> 「我们交易的是未来，需要预测未来；我们交易的是一个点，需要选择关键点；我们买的是上涨，希望回避回调。」（第三章 开篇）

## I — 自述

作者给出五种预测未来的口径，并强调「预测能到多细」取决于口径：

1. **结构预测**：本级别浪形走完没有、下一级结构是什么——决定「接下来该走哪一浪」。
2. **形态预测**：当前是剪刀/镰刀/双节棍/三角形/上倾/下倾——决定「这波调整有多深、C 浪有多强」。
3. **周期预测**：当前处在哪个周期、周期之间如何配合——决定「这波行情能走多久」。
4. **位置预测**：本级别处在大一级的哪一段——决定「目标在哪、该不该做」。
5. **关键点预测**：阻力位/支撑位/多空分界点——决定「在哪个价位转向」。

五者的关系是递进的：结构定方向，形态定深度，周期定时间，位置定目标，关键点定触发。作者不承诺「精确点位」，只承诺「把可能的路径与关键点说清楚」，并用「具备结构条件/结束信号」给出可验证的预测。

这也是全书对「波浪理论不能预测」这一批评的回应：不是精确预测点位，而是**用结构给出可被后市验证的路径与关键点**。

**原书案例（图 3-1~3-11）**：作者用五种口径逐一预测上证指数、沪深 300、中国石油等走势，并给出关键点。原文未说明预测是否兑现。

**合成演练（原书未提供该场景的完整案例）**：某股当前结构为周线 C 浪上涨中、形态为「双节棍」调整结束、周期处在月线（A）上涨的第 1 浪、位置在年线 {1} 浪、关键点为 25.10。五口径结论：结构→预期 C 浪延续；形态→调整结束、C 浪强劲；周期→月线级别；位置→目标看年线结构条件；关键点→上破 25.10 触发。预期输出：五口径预测表＋关键点＋触发条件。

## A2 — 未来触发

1. 「接下来会怎么走？」「能涨到哪？」
2. 需要把「预测」说清楚而不是拍脑袋时。
3. 英文信号：*"forecast the next move"*、*"where will it go"*、*"走势预测"*。

**与相邻能力的区分**：
- 与 **U01**：U01 定级，U14 用定级结果预测未来。
- 与 **U06**：U06 是「当前位置决定策略」，U14 是「预测未来路径」。
- 与 **U02**：U02 判结束信号，U14 用结束信号预测下一段。

## E — 执行步骤

**输入契约（缺项先问）**：当前结构/形态/周期/位置/关键点五项信息；目标预测周期。

**步骤**：
1. **结构预测**：本级别走完没有、下一级是什么。完成标准：结构结论一行。
2. **形态预测**：当前形态与预测含义。完成标准：形态＋预测一行。
3. **周期预测**：周期位置与持续时间。完成标准：周期结论一行。
4. **位置预测**：目标区间。完成标准：目标区间一行。
5. **关键点预测**：触发价位。完成标准：关键点一行。
6. **汇总**：五口径是否一致；不一致时说明分歧。完成标准：一致性检查。

**判停点**：五项信息缺三项以上，停止，输出「预测条件不足」。

**输出契约**：| 字段 | 内容 |（结构/形态/周期/位置/关键点/一致性）

## B — 边界

- **不要用于**：把预测当保证；五项信息不足时硬预测；用预测替代止损。
- **作者警告的失败模式**：只用一个口径预测；预测与结构条件脱节。
- **作者盲点**：预测无量化公式；事后验证缺失；年线样本不足。
- **失效条件**：结构演变；极端行情；数据不足。
