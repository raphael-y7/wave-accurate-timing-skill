## R — 原文

> 「日线{a3}上破“{b2}下移”高点和{b3}验证收在{a3}低点以上，都是周线B5调整转势的信号和预期C5上涨的顺势点，因验证B5收在A5低点以上，也是预期月线“（C1）上移”和年线顺势点，设止损于B5或A5低点以下。」（第四章 第九节）

> 「C 上破 A 高点确立高一个级别的上涨趋势，预期'B 上移'内次一级三浪回调出现结束信号，验证收在 B 浪低点以上的点，才是高两级上涨的顺势点。」（第四章 第六节 开篇）

> 「成功率高的周线顺势点，需在月线上涨趋势或预期上涨中寻找和等待周线“C 上移”或预期 C 上涨的顺势点。在月线下跌趋势中，即使在周线上涨（反弹）顺势点交易，成功率也低。……成功率高的月线顺势，需在年线上涨趋势或预期年线上涨中寻找和等待月线（C）或预期（C）上涨的顺势点。」（第四章 第七节、第八节）

## I — 自述

顺势点回答的是「趋势已经确立，回调到哪里可以上车」。它有三个必要条件，缺一不可：

1. **高一级趋势已确立**：必须有「次一级三浪上破本级别前高」之类的信号，把高一级方向定下来（见 U01）。趋势没确立时的「回调买入」只是猜底。
2. **本级别调整出现结束信号**：回调走到 {a}{b}{c} 三浪（或更复杂结构）并且出现「上破前高＋验证收住」的结束信号（见 U02）。
3. **验证收在关键低点之上**：回调不能破掉前面的关键低点，否则就是趋势反转而非回调。

作者强调**顺势点的质量取决于级别组合**：在年线上涨中做月线顺势点，成功率高；在月线下跌趋势中做周线顺势点，成功率低。这就是「小周期波幅必须符合大周期趋势」的实际用法——同一个「回调结束」，放在不同大周期背景下，性质完全不同。

操作上，顺势点比逆势点安全（因为趋势已确认），但收益空间相对小；作者建议顺势点可以作为「主仓」位置，逆势点只做「观察仓/分批首仓」。

## A2 — 未来触发

1. 「趋势已经涨起来了，回调到哪里可以买？」「追不追？」
2. 「这个是回调还是反转？」——需要区分「顺势点」与「破位」。
3. 想给已有持仓加仓，找「加仓点」。
4. 英文信号：*"buy the pullback"*、*"trend following entry"*、*"is this a correction or reversal"*。

**与相邻能力的区分**：
- 与 **U04 逆势点**：逆势点是趋势未确立/调整极端时抢反弹，顺势点是趋势确立后回调买；两者方向与风险不同。
- 与 **U02**：U02 判结束信号，U07 用结束信号定顺势点。
- 与 **U06 位置策略**：U06 回答「这个位置该用顺势还是逆势策略」，U07 是「用顺势策略时具体怎么找点」。
- 与 `dow-theory-classic-skill`：道氏用「趋势线＋相互验证」确认趋势后顺势，本能力用「次一级三浪上破」确认，判据不同但理念相近，不要混用标签。

## E — 执行步骤

**输入契约（缺项先问）**：
- 高一级趋势是否已确立（U01 结论＋突破价位）；
- 本级别调整结构（{a}{b}{c} 或更复杂）；
- 关键低点价位。

**步骤**：

1. **确认高一级趋势**：无确立信号则停止，转 U04 逆势流程。完成标准：写出「趋势确立＋突破价位」。
2. **等本级别调整结束信号**：调整走完 {a}{b}{c}，并出现「上破前高＋验证收住」。完成标准：写出「结束信号＋验证结果」。
3. **确认不破关键低点**：回调低点必须高于前一个关键低点（否则是反转）。完成标准：写出「关键低点价位＋未破结论」。
4. **入场与止损**：入场价为结束信号确认价；止损为调整浪起点（{a} 低点或结构最低点）以下。完成标准：入场价＋止损价＋仓位。
5. **设目标与出局**：目标为高一级浪具备结构条件处（主动出局），反转信号为被动出局。完成标准：目标价＋两类出局条件。

**判停点**：若趋势未确立，停在步骤 1，明确告知「现在不是顺势点场景」。

**输出契约**：

| 字段 | 内容 |
|---|---|
| 趋势确立 | 有/无＋突破价位 |
| 调整结构 | 类型＋结束信号 |
| 关键低点 | 价位＋未破确认 |
| 入场/止损 | 价位＋仓位 |
| 目标/出局 | 目标价＋主动/被动出局条件 |

## B — 边界

- **不要用于**：趋势未确立时的「回调买入」；月线下跌趋势中做周线顺势点（作者明确说成功率低）；把「破位反抽」当顺势点。
- **作者警告的失败模式**：小周期波幅不符合大周期趋势（第二章）；把反弹当顺势。
- **作者盲点**：趋势确立信号本身可能滞后；A 股 T+1 使「突破即买」难以执行；跳空使止损失效。
- **失效条件**：震荡市频繁假突破；数据复权口径不一致；流动性不足。
