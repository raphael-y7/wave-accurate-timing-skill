## R — 原文

> 「逆势交易要在调整浪极端之时（调整浪内部结构一次或二次分解具备结构条件）逆势抓底；或在大周期上涨趋势成立后，逆势抓小周期调整之底，顺大周期上涨之势。」（第一章 第六节）

> 「波浪理论内部结构分析力求精准找到各周期与各结构逆势点、顺势点，具备结构条件的主动出局点，出现结束信号的被动出局点、技术止损点……」（第一章 第一节 开篇）

> 「{b}、'{b}下移'、'{b}再下移'都是逆势交易，哪种逆势交易成功率高、后市回报高呢？」（第一章 第六节）

## I — 自述

作者把「买卖点」这个混用词拆成**六类**，让任一分析结论必须落到某一类，否则判为「尚无结构依据」：

1. **逆势点**：调整浪（或反弹浪）内部结构一次/二次分解到极端、具备结构条件之处的那个点。在这里逆势抓底（或抓顶），顺更大周期之势。它是最早、也最危险的买点，必须分批。
2. **转势点**：调整（反弹）结束信号出现、并验证收在关键低点（高点）之外的点。原趋势反转的确认点。
3. **顺势点**：高一级趋势已确立后，本级别调整出现结束信号、验证收在关键低点（高点）之上的点。
4. **主动出局点**：上涨（下跌）具备结构条件时按计划离场。
5. **被动出局点**：出现反转（结束）信号后被迫离场。
6. **技术止损点**：浪形起点之外的那条线，破了就认错。

**逆势抓底的完整流程**（本章重点）是：先确认大周期方向（定级）→ 找调整浪 → 判分解次数（越极端越好）→ 在具备结构条件处**分批**建仓 → 止损放浪起点之外 → 若继续演变则等下一个极端点（{b} 下移/{c} 下移）再补 → 直到结束信号出现、转为顺势持有。作者特别强调：三种逆势交易（{b}、{b}下移、{b}再下移）中，越靠后的极端点成功率越高、回报越高，但位置也越难等。

## A1 — 应用示例

**原书案例（图 1-18~1-25，上证指数、沪深 300、神州信息等）**：日线三浪「剪刀」式调整中，作者在 {b}、{b}下移、{b}再下移 三种反弹位置标出「逆势点」，并用「逆势抓小周期调整之底顺大周期上涨之势」给出完整流程；例如神州信息在 16.85→13.66 一段标出逆势点与止损位。原文未逐一说明后续收益。

**合成演练（原书未提供该场景的完整案例）**：某股周线确立上涨（大周期方向明确）后，日线走 {a} 18.60→{b} 16.40→{c} 12.05→{b}下移 14.10→{c}下移 11.32。判定：日线「剪刀」式二次分解，{c}下移 11.32 为极端逆势点（具备结构条件）。操作：在该处建 1/3 仓，止损 11.32 以下；若后市继续 {b}再下移 13.05、{c}再下移 10.18，则在 10.18 再补 1/3；直到 {a} 上破 {b} 高点并验证收住，转顺势持有、止损上移至 {c}再下移 10.18 以下。预期输出：交易点分类表（逆势/转势/顺势/出局/止损）＋分批计划＋止损链。

2. 「逆势买和顺势买有什么区别？我该等哪个？」
3. 想把「买卖点」说清楚，但发现概念混在一起。
4. 英文信号：*"should I buy the dip"*、*"countertrend entry"*、*"when to enter"*、*"is this a bottom"*。

**与相邻能力的区分**：
- 与 **U02**：U02 判「结束没有」，U04 判「在哪类点下单、怎么分批」。
- 与 **U07 顺势点**：U04 的逆势点是「调整极端抢反弹」，U07 的顺势点是「趋势确立后回调买」，两者方向相反、止损不同；不要用逆势点替代顺势点。
- 与 **U08**：U04 只给入场分类，止损/目标/出局由 U08 统一声明。
- 与 `wave-accurate-counting-skill`：数浪入口解决「结构怎么数」，本能力解决「数出来之后在哪买」。

## E — 执行步骤

**输入契约（缺项先问）**：
- 大周期方向结论（U01 输出）；
- 调整浪结构标注（{a}{b}{c} 与各级下移）；
- 关键高低点价位；
- 用户的风险偏好（决定分批比例，原书只给「分批」，未给统一比例）。

**步骤**：

1. **确认大周期方向**：无明确大周期方向时，逆势点只能做观察仓，不得重仓。完成标准：写出「大周期＝？方向＝？」。
2. **分类交易点**：把当前点位归入六类之一（逆势/转势/顺势/主动出局/被动出局/技术止损）。完成标准：分类＋依据（结构条件/结束信号/趋势确立）。
3. **定分批计划**：逆势点建首仓（建议 ≤1/3），{b}下移/{c}下移 再补；每批止损都在对应浪起点之外。完成标准：分批表（价位/比例/止损）。
4. **设止损链**：每批止损独立，随新低点下移只上移不下移（做多）。完成标准：止损链表格。
5. **转顺势**：结束信号确认后，把「逆势仓」转为「顺势持有」，止损上移。完成标准：转仓条件＋新止损。

**判停点**：若大周期方向不明或结构标注不确定，停在步骤 2，输出「只能观察，不建仓」。

**输出契约**：

| 字段 | 内容 |
|---|---|
| 交易点分类 | 六类之一＋依据 |
| 大周期方向 | 上涨/下跌/不明 |
| 分批计划 | 价位、比例、每批止损 |
| 止损链 | 当前有效止损＋上移条件 |
| 转顺势条件 | 结束信号＋验证要求 |

## B — 边界

- **不要用于**：大周期方向不明时重仓逆势；把「跌得多」当「到底了」；在无结构标注时凭感觉抄底。
- **作者警告的失败模式**：「逆势抓周线、月线之底出错机会大，止损点容易被打掉」；三种逆势交易中越早的点成功率越低。
- **作者盲点**：A 股 T+1 使「当日跌破止损」无法执行；涨跌停跳空使「低点以下止损」可能穿越；书中无失败率统计。
- **失效条件**：单边急跌中逆势点连续被打；流动性不足导致无法分批；停牌复牌跳空。
