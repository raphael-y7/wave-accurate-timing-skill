# 决策规则速查 — 精准择时——波浪理论实战策略

| 能力 | 一句话规则 |
|---|---|
| 定级定方向 | 先定「现在在哪一级、往哪走」，再谈买卖点 |
| 结构条件与结束信号 | 「具备结构条件」不等于「结束」，两者必须分开 |
| 调整形态词典 | 剪刀/镰刀/双节棍三式＋四种特殊结构，各有预测与关键点 |
| 逆势抓底与三类交易点 | 逆势点、转势点、顺势点分清楚，各自止损不同 |
| 多空分界点与上移下移 | 分界点是免费止损位；标号上移下移不等于换级别 |
| 位置决定策略 | 同一形态位置不同，策略、目标、止损全不同 |
| 顺势点 | 大一级趋势确立后，本级别调整结束才是顺势点 |
| 止损·目标·出局 | 止损放浪起点外，目标放高一级结构条件处，主动/被动出局分开设 |
| 短线买点 | 以周线状态为准的四类短线买点 |
| 板块选股 | 先板块后个股的四层漏斗 |
| 高胜率结构与共振 | 一个点被几级同时解释，就是共振买点 |
| 多周期复核 | 大级别看不清就逐级下钻，找隐藏的转势信号 |
| 多标注与不确定性 | 多标注时不选边也能下单：等条件、等验证、或降仓 |
| 走势预测法 | 结构、形态、周期、位置、关键点五种预测口径 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
