## I — 自述

这套方法的第一步不是找买点，而是先回答「现在处在哪一级、往哪个方向走」。它把艾略特的固定浪级命名改成相对坐标：以**当前正在运行的最高级别推动浪**为「基础浪」，其内部为「细分浪」，再往下是「细分浪中细分浪」。定级之后，方向由**次一级三浪的突破**来确立——例如周线的 C 浪上破同级别 A 浪高点，就说明高一级（月线）的（A）浪上涨已经确立；反过来，下破则方向改写。

关键在于「逐级递归」：先用同一套规则把周线级别定下来，再用同样方法把周线内部拆成日线级别，层层向下。级别一旦定错，后面的止损位、目标位、仓位全部错位，所以作者把它放在全书第一章第一节。

定级完成后还要回答三问：这个位置适不适合交易、该等什么样的机会、风险回报比是多少。三问答不上来，就说明级别没定清，要退回上一步。

**合成演练（原书未提供该场景的完整案例）**：给定某指数周线图，标注出 A1 高点 21.30、C1 高点 22.05；C1 上破 A1 后，按规则判定「月线（A）上涨确立」，并把交易级别从周线上调为月线；随后在月线级别上等待第一次日线 {a}{b}{c} 调整结束信号，作为顺势点入场，止损放该调整浪起点（{a} 低点）以下。预期输出：级别结论（月线）、方向结论（上涨）、下一级观察对象（日线三浪调整）。

## A2 — 未来触发

用户会在这些情境下需要它：

1. 「这只股票现在是什么级别、往上还是往下？」「该看日线还是周线？」
2. 拿着一张多周期图问「这波上涨是周线级别还是月线级别？」
3. 复盘时发现「我上次止损被打掉，是不是级别看错了？」
4. 英文信号：*"what wave degree is this"*、*"is this a weekly or monthly trend"*、*"which timeframe should I use"*。

**与相邻能力的区分**：
- 与 **U06 位置决定策略**：U01 只回答「在哪一级、往哪走」，U06 回答「这个位置该用哪套策略、目标多大」；U06 以 U01 的结论为输入。
- 与 **U14 走势预测法**：U01 是定级，U14 是定级之后预测未来结构；不要用 U14 的「五种预测法」替代定级。
- 与已装 `wave-accurate-counting-skill`（陈晓东《精准数浪》）：数浪入口解决「怎么数浪、浪级怎么标」，本能力解决「数完之后怎么定方向与级别并据此择时」；用户只说「帮我数浪」时走数浪入口，说「现在该不该买/是什么级别」时走本能力。
- 与 `wave-theory-skill`（艾略特原著解读）：那是理论体系与九级浪标注，本能力是「用突破定方向」的实操判定，不展开理论。

## E — 执行步骤

**输入契约（缺一项就先问，不猜）**：
- 多周期 K 线数据（至少含本级别与次一级，如周线＋日线）；
- 当前已标注的浪级结构（若用户未标注，先按可见的推动/调整段粗标，并声明「粗标待验证」）；
- 关键高低点价位。

**步骤**：

1. **锚定基础浪**：找出正在运行的最高级别推动浪，把它定为「基础浪」；写出「第 1 浪起点在哪个价位/哪根 K 线」。完成标准：能用一句话说出「当前基础浪＝X 级别，起于 Y 价位」。
2. **递归定级**：向下拆一级，确认次一级是否已走出三浪/五浪结构；向上确认本级别是否已被高一级的突破信号确认。完成标准：给出「本级别＝？、高一级＝？、方向＝？」三行结论。
3. **方向确认**：用「次一级三浪上破本级别前高＝高一级上涨确立；下破前低＝方向改写」写方向结论。完成标准：方向结论必须带**具体突破价位**，不能只写「看涨」。
4. **三问闸门**：位置是否适合交易？该等什么机会（具体到结构/信号）？风险回报比是否算得清？任一答不上来→退回步骤 1。完成标准：三问全部有具体答案才进入下一步。

**判停点**：若多周期数据不足（只有日线），停在步骤 2，输出「无法定级，需补周线/月线数据」，不得用日线替代。

**输出契约**：

| 字段 | 内容 |
|---|---|
| 基础浪 | 级别＋起点价位 |
| 本级别 | 级别名（周线/月线/年线…） |
| 高一级 | 级别名＋方向 |
| 方向结论 | 上涨/下跌/震荡＋确立依据（突破哪个价位） |
| 交易级别建议 | 用哪一级做交易，为什么 |
| 待验证项 | 粗标处、缺数据处 |

## B — 边界

- **不要用于**：只有单一周期数据时（无法递归定级）；纯基本面/消息面判断；指数与个股级别混用（个股年线样本常不足 20 根）。
- **作者警告的失败模式**：不先定级就找买点，止损与目标全错；「形态是三浪、内部是一浪」的错位（第八章）会让级别判错。
- **作者盲点**：A 股个股上市年限短，年线级别判定样本不足（书中年线结论多为事后验证）；多标注（「或 A 或 B」）时方法不给唯一解，须降仓或等验证（见 U13）。
- **与相邻方法混淆**：不要把「均线多空排列」当级别判定；不要把「周线 C 上破 A 高点」与「价格突破前高」混为一谈——前者要求 C 浪与 A 浪同级别，后者只是价格比较。
- **失效条件**：极端行情（连续涨跌停、停牌复牌）导致突破与验证失真；数据复权口径不一致时，高低点会错位。
