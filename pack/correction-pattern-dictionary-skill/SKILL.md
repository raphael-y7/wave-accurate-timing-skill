> 「“镰刀”式调整是在预期的三浪调整多空争夺过程中空头明显占优的一种结构模式（见图 10），{b} 浪分解成 {a}、{b}、{c} 三浪反弹下倾结构，其中 {b} 浪再次分解成 {a0}、{b0}、{c0} 三浪调整，是 {b} 浪二次分解的结果。」（特色术语 2）

> 「“双节棍”式调整是预期的三浪调整多空争夺难解难分（见图 11），{b} 浪一次分解成 {a}、{b}、{c} 三浪反弹下倾结构，后三浪同时再分解的结果，最终以空头占优结束调整。」（特色术语 3）

## I — 自述

复杂调整看上去千变万化，作者把它收敛成**三种基本式样**，全部由 {b} 浪的「分解」产生：

- **剪刀式**：{b} 浪一次或二次分解成 {a}{b}{c} 反弹下倾结构，反弹高点 {b} 与低点 {c} 逐级下移，形似剪刀张口向下。分解次数越多，下跌越持续。
- **镰刀式**：{b} 浪一次分解后，其中的 {b} 浪**再分解**成 {a0}{b0}{c0}，反弹高点一级比一级低、低点不断下移，末端急跌，形似镰刀；特征是「空头明显占优」。
- **双节棍式**：{b} 浪一次分解后，这三浪**同时**再分解，多空争夺难解难分，最终空头占优；形似双截棍两节。它最容易产生多空分界点，也最容易演变成不规则结构。

在这三式之外，还有四种特殊结构：**调整上倾**（本应下跌的 B 浪调整实际向上，预示 C 浪强劲）、**反弹下倾**（本应上涨的 B 浪反弹实际向下，预示 C 浪重挫）、**三角形**（收敛，确立时预示 C 浪强劲）、**不规则结构**（市场没按常规走但后市已确认本浪结束）。

这套词典的价值在于**预测力**：看到某式，就能预判「这个调整会有多深、后面 C 浪会有多强、关键点在哪、止损放哪」，而不是事后数浪。作者强调：形态识别必须以先定级为前提，同一形态在不同位置含义不同（见 U06）。

## E — 执行步骤

**输入契约（缺项先问）**：
- 调整段的完整浪形标注（{a}{b}{c} 及各级下移/上移标号）；
- 该调整所处的位置（哪一级、A/B/C 哪一段）；
- 关键高低点价位。

**步骤**：

1. **确认这是调整浪而非推动浪**：数出 {a}{b}{c} 三浪骨架；若形态更像五浪推动，停止，转 U01 定级。完成标准：写出「调整浪成立＋三浪骨架」。
2. **判分解次数与式样**：
   - {b} 浪内部只有一次 {a}{b}{c} → 一次分解；
   - {b} 浪内又出现 {a0}{b0}{c0} → 二次分解（镰刀式）；
   - {a}{b}{c} 三浪同时再分解 → 双节棍式；
   - {b} 与 {c} 逐级下移、无更深分解 → 剪刀式。
   完成标准：给出「式样＋分解次数＋依据标号」。
3. **查四种特殊结构**：是否上倾/下倾/三角形/不规则；若符合，追加标签与预测。完成标准：特殊结构有/无＋依据。
4. **输出预测与关键点**：按式样给「下跌持续性/后续 C 浪强度」预测、关键点（{c} 低点/多空分界点）、止损位。完成标准：预测句＋关键点价位＋止损价位三件齐。

**判停点**：若位置未定（不知道在 A/B/C 哪一段），停在步骤 1，先转 U01/U06 定位置；形态标签离开位置无意义。

**输出契约**：

| 字段 | 内容 |
|---|---|
| 式样 | 剪刀/镰刀/双节棍/普通三浪 |
| 分解次数 | 一次/二次/三次（三次以上无通用判据，标注「经验口径」） |
| 特殊结构 | 上倾/下倾/三角形/不规则/无 |
| 预测 | 调整持续性与后续 C 浪强度 |
| 关键点 | {c} 低点、多空分界点（如有） |
| 止损位 | 浪起点之外 |

## B — 边界

- **不要用于**：形态识别前未定级（离开位置，同一形态含义不同）；把「像剪刀」当「一定是剪刀」（作者自己给「或/改」多标注）；年线级别形态（样本不足）。
- **作者警告的失败模式**：把不规则结构当标准结构操作；分解次数事后才知（不能事前数）。
- **作者盲点**：式样识别依赖事后标注（书中大量「或 A 或 B」）；「分解次数」与浪级的映射是归纳，无原文阈值（见 needs-review NR-02）。
- **失效条件**：极端行情下形态被破坏；数据复权口径不一致导致高低点错位。
