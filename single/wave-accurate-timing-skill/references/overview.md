# 精准择时——波浪理论实战策略（书级概览）

## 基本信息

- 书名：精准择时——波浪理论实战策略
- 作者：陈晓东（"波浪理论内部结构分析"创立者；同作者另有《精准数浪》）
- 出版：山西出版传媒集团·山西人民出版社，2023 年 6 月，ISBN 978-7-203-12813-7
- 类型：股票/期货技术分析实操手册
- 读者目的：辅助 A 股股票投资分析，可执行交易方法论优先

## 一句话主旨

通过把每一浪拆解到次一级三浪、以"结束信号"确认浪的终点，给出一套在任意周期事前定位逆势点、转势点与顺势点，并据所处位置设定止损、目标与出局点的择时方法。

## 骨架（一级论点）

1. **定级与定方向**：用"次一级三浪上破本级别前高/下破前低"确立趋势方向与级别，逐级递归；不先定级，后面所有点位失效。
2. **分段与终点**：每浪终点只由"本级浪形通过次一级三浪出现结束信号"确认；"具备结构条件"只是候选，仍可演变。
3. **三类交易点**：逆势点（调整极端逆势抓底）、转势点（结束信号确认）、顺势点（趋势确立后回调结束）；出局分主动/被动。
4. **形态词典**：剪刀/镰刀/双节棍三式＋调整上倾/反弹下倾/三角形/不规则/浪中浪/组合结构。
5. **层级约束**：小周期波幅必须符合大周期趋势；位置决定策略、目标、止损。
6. **胜率工程**：短线买点、板块选股、高胜率结构清单、共振、风控与仓位。

## 关键术语（作者用法）

| 术语 | 作者的定义 |
|---|---|
| 基础浪 | 正在运行的最高级别推动浪；其内次一级为细分浪 |
| 具备结构条件 | 浪形走完最小构成，可结束但仍可演变；不等于结束 |
| 结束信号 | 次一级三浪反转并验证收在关键低点/高点之外 |
| 逆势点 | 调整浪内部一次/二次分解到极端处的点，逆势抓底 |
| 转势点 | 结束信号出现并验证收在关键低点/高点之外的点 |
| 顺势点 | 高一级趋势确立后，本级别调整结束并验证收在关键低点之上的点 |
| 关键买点 | 本级别调整结束＋位置使目标可上调＋止损空间可接受 |
| 多空分界点 | 双节棍等结构具备结束条件时的低/高点，破与不破决定多空归属 |
| 上移/下移 | 同一浪级标号因结构演变整体抬高/降低的重新标注，级别不变 |
| 剪刀式 | {b} 浪一次/二次分解成 {a}{b}{c} 反弹下倾，逐级下移 |
| 镰刀式 | {b} 浪一次分解后其 {b} 浪再分解，反弹逐级降低、末端急跌 |
| 双节棍式 | {b} 浪一次分解后三浪同时再分解，多空难解难分 |
| 调整上倾 | 本应下跌的 B 浪调整实际向上，预示 C 浪强劲 |
| 反弹下倾 | 本应上涨的 B 浪反弹实际向下，预示 C 浪重挫 |
| 浪中浪 | 调整结构内含另一调整结构，不改变级别 |
| 一点三级共振 | 同一点同时是本级/高一级/高两级的逆势点或顺势点 |
| 位置 | 本级别浪处在大一级浪的哪一段，而非价格高低 |
| 主动/被动出局 | 主动＝结构条件具备按计划走；被动＝反转信号出现被迫走 |

## 批判要点（B 段来源）

- 案例集中在 2019-2022，缺少 2015/2018 与注册制后样本；
- 结论未做后续跟踪，无失败率统计；
- 事后标注：同一段 K 线多种标注（"或 A 或 B"），事前无唯一解；
- A 股 T+1、涨跌停、跳空使"低点以下止损"可能无法执行；
- 年线级别样本不足（个股上市年限短）；
- 案例为事后选出的大牛股，存在选择偏差。
